# Task5_Neural-_Style_Transfer<br>
## Overview<br>
This project applies the artistic style of one image to another using Neural Style Transfer with TensorFlow Hub.<br>
## Features<br>
* Loads a content image and a style image<br>
* Uses a pre-trained TensorFlow Hub model<br>
* Generates a stylized output image<br>
* Saves the final output automatically<br>
## Technologies Used<br>
* Python<br>
* TensorFlow<br>
* TensorFlow Hub<br>
* NumPy<br>
* Pillow<br>
* Matplotlib<br>
## Files<br>
* Neural_Style_Transfer.ipynb<br>
* content.jpg<br>
* style.jpg<br>
* output.png<br>
## How to Run<br>
* Upload content.jpg and style.jpg to Google Colab.<br>
* Run all notebook cells.<br>
* The stylized image will be saved as output.png.<br>
## Result<br>
The model successfully transfers the artistic style from the style image to the content image using deep learning.<br>
